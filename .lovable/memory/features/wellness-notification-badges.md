---
name: Pastilles des wellness athlètes
description: Pastilles rouges pour les wellness saisis, analogues aux RPE, dans toutes les disciplines.
type: feature
---
Afficher des pastilles rouges lorsque les athlètes renseignent leur wellness, sur le même principe que les notifications RPE prévu/réel, pour toutes les catégories et disciplines. Les pastilles disparaissent à la consultation du wellness par le membre du staff concerné. Ne pas réactiver les e-mails.
